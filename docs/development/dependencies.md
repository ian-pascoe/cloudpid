# Patched and pinned dependencies

Some dependencies carry a patch (`patches/`) or an exact pin. When upgrading one, `bun install` fails on a stale patch (`patchedDependencies` in the root `package.json`; `bun patch <pkg>` starts a new one): check whether upstream fixed the problem, drop the patch if so, else port it, then run the checks listed for it.
