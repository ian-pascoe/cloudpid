# Effect wraps pi-durable; it does not replace its core

Effect is the application language: infrastructure, Workers, Durable Object wiring, the RPC protocol, services, configuration, and extension logic. pi-durable's Harness, commits, documents, and task phases stay native Promise and Chord `Context` code. Adapters in `packages/effect-durable` (`defineEffectTool`, `effectHook`, `effectSection`, `effectTask`) bridge Chord cancellation to fiber interruption and typed failures to tool error results (`effectTask`: to a `failed` task outcome). pi-durable owns durability, replay, and scheduling, and a second Effect-native scheduler or full re-wrapping would fight that model rather than add to it.
