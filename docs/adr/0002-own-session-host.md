# Session DOs host pi-durable directly, not through Cloudflare's PiHarness

`agents/harness/pi` (`PiHarness`, beta) hosts pi-durable on the Agents SDK's `Agent` class and Lifecycle jobs. It polls every 30 s for background work and reads `pi.live` to find sleep deadlines, because pi-durable 1.3.0 keeps its timers in memory. pi-durable's next release adds `HarnessOptions.onWake` and `Harness.wake()`, which give the host the earliest sleep and whether work is active. With them, our own host is about 100 lines: arm the Durable Object alarm and call `resume()`, as pi-durable's own `test-workers` do. That keeps the Agents SDK out of the Session DO and the DO wiring in our Effect code. Until `onWake` ships, the host arms a 60 s heartbeat alarm while any task is live. We still use `agents/browser` as a library (see ADR-0007).
